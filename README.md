# caa-graduation-project

中国美术学院2027届中方毕业设计。研究国美历届作品档案、孤山历史公共空间及艺术文化的持续社会传播。

公开研究网站：**https://hugo31112.github.io/caa-graduation-project/**

当前版本：**Research Website v0.4 | 2026-10-23**

完整连续滚动网页，包含项目概述、孤山历史与现状、用户需求、线下架构、交互与案例、资料来源。v0.3补充历史照片与重访对照，增强场地研究图文，统一传播、档案和交互信息图；原功能架构与冲突矩阵保留。

## 仓库结构

GitHub Pages沿用main分支的/docs目录。

## 中英文展示

`docs/index.html` 为中文版，`docs/index-en.html` 为英文版，页顶可切换语言；启用JavaScript时保留当前章节位置，不启用时仍可使用静态链接。两版均可离线打开，保持连续滚动。英文覆盖正文、表格、图注、替代文字及10张SVG；中文原图保留，英文图位于 `docs/assets/diagrams/en/`。

中文内容更新后，补充或调整 `docs/locales/en.json` 与 `en-diagrams.json` 的对应翻译，再用Python 3运行 `tools/build-english.py` 重新生成英文页与图。生成器发现缺失翻译会报错；不要将英文输出当成独立编辑源。英文稿是本项目工作译文，历史资料的差异与研究待核状态保持一致。

v0.4双语版本经项目负责人确认发布；后续修改继续采用本地优先、明确确认后发布的流程。
