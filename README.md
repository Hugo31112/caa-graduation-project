# caa-graduation-project

中国美术学院2027届中方毕业设计。研究国美历届作品档案、孤山历史公共空间及艺术文化的持续社会传播。

公开研究网站：**https://hugo31112.github.io/caa-graduation-project/**

当前版本：**Research Website v0.3 | 2026-10-22**

完整连续滚动网页，包含项目概述、孤山历史与现状、用户需求、线下架构、交互与案例、资料来源。v0.3补充历史照片与重访对照，增强场地研究图文，统一传播、档案和交互信息图；原功能架构与冲突矩阵保留。

## 仓库结构

GitHub Pages沿用main分支的/docs目录。

    docs/
    ├── index.html
    ├── .nojekyll
    ├── css/       # 连续阅读、双语功能备注与图文样式
    ├── js/        # 目录定位
    └── assets/    # 12幅图片、10个SVG（含4套手机布局）

网页与素材采用相对路径，无需构建。图像年代、资料状态与原始来源见正文图注和页尾引用。原始调研、录音、内部过程文件与账号凭据不在公开仓库范围内。
