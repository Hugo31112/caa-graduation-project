# caa-graduation-project

中国美术学院 2027 届中方毕业设计。研究国美历届作品档案、孤山历史公共空间及艺术文化的持续社会传播。

公开研究网站（GitHub Pages）：

**https://hugo31112.github.io/caa-graduation-project/**

当前公开网站版本：**Research Website v0.2 | 2026-10-22**（连续滚动网页：项目概述 · 场地现状 · 用户需求 · 线下架构 · 交互与案例 · 资料来源）。

## 仓库结构

```
docs/            # 公开网站（GitHub Pages 来源，main 分支 /docs）
├── index.html   # v0.2 连续滚动研究网页
├── css/         # reading.css / function-key.css
├── js/          # reading.js
└── assets/      # 图片与 SVG 关系图（来源见网页文末引用）
```

仓库根目录用于整个毕业设计项目的公开内容；原始调研与过程文件不在此仓库范围内。
